# Security Policy

## Supported versions

Only the latest release published on Firefox Add-ons / GitHub Releases receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/m-cro/always-active-plus/security/advisories/new)
rather than opening a public issue.

Include the affected version, steps to reproduce, and the impact you observed. You can expect an initial response within a few days.

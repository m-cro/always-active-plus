Mouse movement on re-entry

Humanize adds a bounded, randomized curve and small timing changes to re-entry. It applies globally as you move the slider. Interpolation 0 leaves mouse movement immediate; higher values slow the generated path. Start and stop smoothness control acceleration and braking. Real moves resume when the generated cursor catches up.

Blocked Keyboard Events

Comma-separated KeyboardEvent.key, KeyboardEvent.code, numeric keyCode, or modifier names. Use Alt+Shift to match a modifier combination.

Modifier names such as Shift or Alt match events while that modifier is held. Commas mean either modifier; use + for combinations, such as Alt+Shift. Use Shift@Alt+Shift to block only Shift with that exact modifier state, or a@none for a without modifiers.
